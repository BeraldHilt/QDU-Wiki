# 有话送你

!!! quote "写在前面"
    这里是学长学姐留给学弟学妹们的话。无论是一句鼓励、一段经验，还是踩过的坑、想说的话，都可以写在这里，把这份温度传递下去。

## 寄语

### 炎黄YH

每个人的大学生活都有自己的意义，多注重价值，莫计较代价。保研猛学的同学**舍**娱乐**得**成就，摆烂60分万岁主义者**舍**学习**得**快乐，只要别无休止内耗，在毕业的时候能够觉得曾快乐过，就是最好的结果。

> —— 炎黄YH

### 玉环YH（24软工）

慎重做选择，同样做好承接苦果的准备。以及不要后悔。  
深度使用 AI，但绝对绝对不要外包思考。  
选择就业的同学，早实习，做真正有含金量的项目，注意基础知识与技能的积累，尤其数学、算法、408 专业课。  
找工作时内推和官网投递比 BOSS 直聘高效得多。多结交朋友、混迹技术社区百利无害，尤其一些比较垂直的领域（如竞赛、某细分行业技术等等）。  
大一或许会是大学最闲适快乐的时光吧……

> —— 玉环YH

### 宵宫（23思政）

去勇敢的尝试，体验不一样的人生。在这个流动和变化的年代，扩大知识面和更多元的知识很重要。史哲政不分家是真的。
学好外语（注意不只是英语）可能会有意想不到的收获。
没有必要的课程可以勇敢的放弃。
文科生不是落后于时代的老学究，不是只会“指挥”的保守派。去广泛的探索时代产物和科技前沿吧。
一定要注意身心健康。好好吃饭好好睡觉。千万，不能，放弃，思考。
好好享受生活吧，打工赚零花的收益不一定比好好休息娱乐的收益高。把自己弄得很累是非常危险的。
“人的一生应该这样度过：当回首往事时，不因虚度年华而悔恨，也不因碌碌无为而羞愧；在临终时能说：‘我把整个生命和全部精力献给了最壮丽的事业。’”  ————《钢铁是怎样炼成的》

> —— 宵宫
